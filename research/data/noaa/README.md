# NOAA 年度 CO₂ 数据存档

来源：[NOAA 原始年度 CSV](https://gml.noaa.gov/webdata/ccgg/trends/co2/co2_annmean_mlo.csv)，[数据与引用说明](https://gml.noaa.gov/ccgg/trends/data.html)。本次读取时间 2026-10-12（Asia/Shanghai），源文件头注明创建时间 2026-10-09。

原始字节未修改，SHA-256：`bdd956e8d7e05ebc3c61ac1f8f8c8cea4a505df56724fba5200b4eb1e0089b2b`。文件包括1959–2025年的67个年度平均值、单位 ppm 及不确定度；来源注释和测站变更说明完整保留。数据提供方可能日后修订，复现固定使用本文件。

数据归属与引用：Xin Lan, NOAA/GML；Ralph Keeling, Scripps Institution of Oceanography。早期观测由 C. David Keeling/SIO 提供。本项目 MIT 许可指原创代码；不能把外部观测数据或 Highcharts 源码当作本项目原创。

`tools/real_data_case.py` 从存档中提取所有完整、连续三年窗口，原值不做变换或补值。65个窗口、15个精确声音事件类别，400 ppm阈值49对冲突，总和165对冲突；在这个数据集合中趋势、峰位、缺失数没有冲突。

完整阈值反例：

| 位置 | 1960–1962窗口 | 2013–2015窗口 |
| --- | ---: | ---: |
| 0 | 316.91 | 396.74 |
| 1 | 317.64 | 398.81 |
| 2 | 318.45 | 401.01 |

逐窗口最小值／最大值归一化、100 cents量化、固定相对时间使两者事件完全相同，而是否存在≥400的值分别false/true。该设置不编码绝对年份、不朗读数值，并非对一个包含完整标签的实际气候图表的结论。未做真人听觉验证。

完整窗口证据附原始年份与来源哈希，并逐年对存档再核对。审计内部的删除缩减反例会单独保存，不能当作完整三年窗口。
